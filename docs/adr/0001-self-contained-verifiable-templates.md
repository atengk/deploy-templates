# 采用“部署配置 + 极简可运行参考应用”的自包含模板形态

部署配置库如果只存放孤立的 `Dockerfile`、Compose 与 YAML 片段，很快会随着基础镜像、构建工具和框架升级而静默腐烂。我们决定为每个技术栈配套维护一份极简可运行的参考应用，使所有部署方案都能被 CI 真实构建、启动和通过健康检查验证，同时保持部署配置与应用源码解耦以便直接拷贝复用。

## 备选方案（Considered Options）

- **仅存放纯部署配置片段**：维护体积小，但无法自动化验证配置是否真正可用。
- **CLI 交互式生成器**：交互体验好，但把部署细节隐藏在模板引擎后面，不利于直接浏览对照和按需抄用。

## 影响（Consequences）

- 每个技术栈需持续维护一份最小参考应用及依赖升级，但换取了每次变更均可端到端验证的可信度。
