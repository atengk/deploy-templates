# 分诊标签（Triage Labels）

工程技能体系统一围绕五个标准分诊角色进行协作。本文件用于将这些标准角色映射到本仓库 Issue 追踪器中实际使用的标签字符串。

| mattpocock/skills 标准角色 | 本仓库实际标签 | 含义说明 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 Issue |
| `needs-info` | `needs-info` | 等待提交者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交由 Agent 独立执行（AFK） |
| `ready-for-human` | `ready-for-human` | 需要人工进一步决策或实现 |
| `wontfix` | `wontfix` | 不予处理 |

当任意技能提及某一分诊角色（例如“应用适合 Agent 自动执行的分诊标签”）时，统一使用上表中对应的实际标签字符串。

如后续仓库调整了标签命名规范，直接修改“本仓库实际标签”列即可。
